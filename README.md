## 🍂 Sobre mim

Olá! Sou **João Paulo**, estudante do 2º ano do Ensino Médio integrado ao curso Técnico em **Desenvolvimento de Sistemas** na ETEC Antônio de Pádua Cardoso.

Atuo como freelancer em projetos web e gosto de desenvolver soluções que sejam funcionais, organizadas e agradáveis de usar. Tenho experiência com criação de páginas, manutenção de aplicações e integração com serviços de banco de dados.

- 🌱 Aprimorando meus conhecimentos em JavaScript e desenvolvimento web.
