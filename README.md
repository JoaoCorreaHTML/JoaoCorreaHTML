## 01 / Sobre mim

Sou **João Paulo**, estudante do curso Técnico em Desenvolvimento de Sistemas na **ETEC Antônio de Pádua Cardoso**, em São Paulo.

Trabalho como freelancer e venho construindo minha experiência com sites, interfaces e aplicações web. Gosto de acompanhar o projeto além da aparência: estrutura, integração com dados, publicação e manutenção também fazem parte do processo.

- 🌱 Atualmente aprofundando meus conhecimentos em JavaScript e desenvolvimento web.
- 🧩 Experiência prática com projetos para clientes e aplicações integradas ao Supabase.
- 🐧 Entusiasta de Linux, personalização de sistemas e tecnologia.
